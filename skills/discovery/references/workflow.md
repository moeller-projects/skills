# Workflow

## Default Flow

1. Frame the problem, scope, and decision that must be made.
2. Audit assumptions, constraints, blind spots, and missing evidence.
3. Generate a few strong options and compare tradeoffs.
4. Recommend the best path and define next actions.

## Fast Path

1. Name the key unknown and the top two options.
2. Recommend the safest next move with one reason.

## Escalation

Use more detail only when correctness, safety, or ambiguity requires it.
