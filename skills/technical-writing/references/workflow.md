# Workflow

## Default Flow

1. Define the audience, purpose, and task the document must support.
2. Build the structure and verify commands, paths, and examples.
3. Write concise content focused on action and understanding.
4. Note gaps, assumptions, and follow-up documentation needs.

## Fast Path

1. Capture the purpose and minimum structure.
2. Add the shortest accurate content that unblocks the reader.

## Escalation

Use more detail only when correctness, safety, or ambiguity requires it.
