# Rule: Structure Over Prose

> Impact: medium

## Description

Prefer scannable sections, lists, and task-oriented sequencing over long prose so the reader can find answers quickly.

## Apply When

- A document explains a workflow, setup path, or architecture topic.

## Checks

- Headings and lists reflect the reader's decision flow.
- Dense narrative is broken into actionable chunks.
- Section voice matches section mode: tutorials are encouraging and second-person, how-tos are imperative, reference is neutral, explanation is discursive. See `rules/diataxis-mode.md`.

## Anti-Pattern

Writing impressive prose that hides the actual workflow or required steps.
