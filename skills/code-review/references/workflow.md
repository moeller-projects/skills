# Workflow

## Default Flow

1. Confirm the target behavior and the quality concern to improve.
2. Identify the highest-severity correctness, complexity, or maintainability issues.
3. Recommend the smallest safe changes in a sensible implementation order.
4. Note validation needs, risk, and any deferred follow-up.

## Fast Path

1. List the top issue and its safest fix.
2. Add one follow-up risk or validation note.

## Escalation

Use more detail only when correctness, safety, or ambiguity requires it.
