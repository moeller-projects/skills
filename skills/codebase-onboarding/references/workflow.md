# Workflow

## Default Flow

1. Scan top-level structure, tooling, and package boundaries.
2. Map major domains, entry points, and execution flows.
3. Extract conventions, hotspots, and onboarding notes.
4. Produce compact artifacts another agent can use immediately.

## Fast Path

1. Identify the main entry points and dominant packages.
2. List the top conventions and hotspots.

## Escalation

Use more detail only when correctness, safety, or ambiguity requires it.
