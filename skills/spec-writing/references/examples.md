# Examples

## Example 1

A product manager shares a rough feature brief. Use this skill to turn it into requirements, acceptance criteria, and open questions before development starts.

## Example 2

A spec changed late in the cycle. Use this skill to surface the diff, explain the impact, and update the required gates or version notes.

## Example 3

A ticket mixes scope, ideas, and policies. Use this skill to separate hard requirements from unresolved assumptions and governance constraints.
