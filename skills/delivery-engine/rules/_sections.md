# Rule: Standard Sections

> Impact: medium

## Description

Organize output into tasks, dependencies, risks, critical path, unknowns, and validation so the plan is reviewable and executable without further clarification.

## Apply When

- Producing any delivery plan or task breakdown.

## Checks

- Tasks, dependencies, critical path, unknowns, and validation steps are all present.
- Unknowns are separated from tasks so they are visible, not buried.

## Anti-Pattern

Producing a flat task list with no dependencies, no critical path, and unknowns hidden inside task descriptions where reviewers will miss them.
