# Examples

## Example 1

A PM shares a confirmed spec for a new checkout feature. Use this skill to turn the
requirements into vertical task slices, surface any unknowns around payment gateway
integration, and identify which tasks are on the critical path before sprint planning.

## Example 2

An engineer needs to migrate a monolith module to a new service. Use this skill to
break the migration into safe, independently deployable steps, explicitly separate
the unknown around data migration strategy into a spike, and estimate only what is
understood.

## Example 3

A team is behind on a release. Use this skill to identify the critical path, mark
which tasks can be parallelized, and expose any unknowns that are silently blocking
the fastest completion route.
