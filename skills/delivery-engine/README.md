# Delivery Engine

Version: 1.0.1

Break work into atomic, shippable tasks with explicit dependencies, critical path, estimates, and definitions of done.

## Includes

- delivery planning workflow
- vertical slicing, unknown exposure, estimate integrity, and critical path rules
- reference workflow and examples

## Best for

- Turning a spec or feature brief into an executable task list
- Planning a refactor or migration safely across multiple engineers
- Exposing delivery unknowns before sprint commitment
- Identifying the critical path that determines earliest completion

## Avoid for

- Writing specifications or requirements — use spec-engine
- Code review or refactoring — use code-quality-engine
- Pure architectural decision-making — use thinking-engine
