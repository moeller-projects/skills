# BLUF — Bottom Line Up Front

Version: 1.0.1

An action-first response style for coding, debugging, operations, and other work where concise, structured answers help the reader act quickly. Accuracy and safety take priority over brevity.

## Use

Apply this skill when the user requests direct, no-fluff, or token-efficient responses, or prefers this style by default. Start with the answer or next action, number multi-step work, keep progress visible, and preserve commands, code, technical terms, and safety qualifiers exactly.

Read [SKILL.md](SKILL.md) for the complete rules and response shapes; [examples](references/examples.md) show before-and-after responses.
