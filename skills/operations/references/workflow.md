# Workflow

## Default Flow

1. Define the change boundary, runtime environment, and primary risks.
2. Map delivery, security, reliability, and rollback concerns.
3. Produce a plan with checks, mitigations, and operational safeguards.
4. Highlight residual risk, rollback triggers, and required approvals.

## Fast Path

1. Identify the top operational risk and the safest rollout path.
2. Add the minimum checks and rollback steps needed to proceed.

## Escalation

Use more detail only when correctness, safety, or ambiguity requires it.
