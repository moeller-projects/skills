# Rule: Meaningful Coverage

> Impact: high

## Description

Increase coverage where it reduces risk, emphasizing critical paths, regressions, and business-important behavior over raw percentages.

## Apply When

- Coverage gaps or missing tests are part of the task.

## Checks

- MUST explain why each proposed test matters.
- MUST focus on the highest-value paths before chasing edge percentages.

## Anti-Pattern

Adding shallow tests only to satisfy a number while important behavior remains untested.
